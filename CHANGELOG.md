# Changelog

## 0.4.0 (2026-10-31)
New app ID, `dev.altayeb.shoebill`. This installs as a new app next to older copies: back up your vault in the old app, then restore it here. New backups are `.shoebillvault` files; older backup files still restore.

## 0.3.0 (2026-10-31)
SMB network shares. DLNA casting. Audio delay and equalizer. Automatic subtitle sync from the audio. Settings backup. Licenses screen. Picked subtitle files now work with frame-rate conversion. The Google Play build has no dialer code.

New name and icon.
